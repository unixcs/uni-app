# 修复商家订单详情空白

## Goal

修复用户支付后商家后台订单详情页整体空白的问题，并确保同类虚拟支付订单即使通知时间、退款摘要或可选关联数据不同，也能稳定展示订单、商品、用户和交易信息。

## Confirmed Example

- 商城订单号：`334517902292559509`
- 本地订单 ID：`10514`
- 已支付，`pay_status=20`
- 虚拟支付交易 ID：`10335`
- `notify_times=1`，存在非零 `last_notify_time`
- 后端 `Order::getDetail(10514)` 可返回完整订单、1 条商品、用户、交易及操作投影

## Requirements

1. 商家订单详情不得因单个展示字段格式化异常而整页空白。
2. 示例订单必须能展示订单号、支付状态、商品、买家、交易与虚拟支付摘要。
3. 虚拟支付最近通知时间必须按 `YYYY-MM-DD HH:mm:ss` 正常显示。
4. `last_notify_time` 为 `0`、空值或有效 Unix 秒时间戳时均不得抛出运行时异常。
5. 非虚拟支付订单、未通知虚拟支付订单及其他现有订单详情行为保持兼容。
6. 排查同类未注册 Vue 实例属性、未导入依赖和不安全枚举/可选字段访问，发现真实缺陷则一并闭环。
7. 添加能在缺陷代码上失败、修复后通过的回归测试或等价自动化断言。
8. 完成定向 lint、商家端生产构建、真实订单后端投影复测及代码 review。
