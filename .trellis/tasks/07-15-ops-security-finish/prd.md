# 备份恢复、运维文档与安全收尾

## Goal
证明新生产可备份、恢复、回滚和长期运维，清理明文/过期文档，交付手动 SSH 换钥方案并完成全局质量门。

## Requirements
- MySQL 完整备份 7 天、binlog 7 天、迁移前备份 30 天、日志 14 天、journal 1 GiB、5 个 release。
- 实际恢复到临时 DB并校验；代码回滚和迁移幂等演练。
- COS/CAM 和外部消息通知明确标记 deferred，不伪称已达到完整异地 RPO。
- 重构 `/mnt/vps/tencent`，移除明文密码/重复过期内容，保留真实拓扑/运行手册/备案页。
- 在项目当前目录交付手动、可回退的 SSH 管理员/deployer 密钥轮换指南。
- 执行 Trellis check/spec update/最终报告；提交和生产同步仍需独立授权。

## Acceptance Criteria
- [ ] 最新备份可恢复，校验值/表计数/上传清单通过。
- [ ] 回滚、版本清理、日志轮转、Timer 熔断和证书续期检查通过。
- [ ] 运维文档无秘密、无旧目录/域名漂移，实际配置与文档一致。
- [ ] 密钥轮换指南包含验证和回退，不自动更换当前密钥。
- [ ] 全量质量检查与最终发布报告完成，deferred 风险明确。
