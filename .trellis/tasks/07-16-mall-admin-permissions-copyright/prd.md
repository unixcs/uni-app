# 修复商城后台权限并移除版权

## Goal

让非超级管理员能够按角色授权执行服务订单操作，并从商家后台所有登录后页面彻底移除萤火商城版权声明。

## Background

本请求包含两个可独立验收的交付物：

1. 服务订单操作权限修复：旧实物商城权限数据未随“开始服务 / 完成服务 / 服务前退款”业务迁移，导致新接口没有可分配的菜单/API绑定。
2. 商家后台版权移除：登录后基础布局仍挂载一个解码后输出“Copyright © 2024 萤火商城V2.0 / YIOVO.COM”的全局页脚组件。

## Requirements

- R1：完成服务订单菜单、API、菜单-API和既有角色授权的完整权限链路修复。
- R2：清理旧实物订单权限项，包括发货、确认收货、订单导出及发货管理相关子项。
- R3：三个服务动作必须可独立分配，并同时控制前端按钮和后端接口访问。
- R4：彻底删除商家后台登录后页面的指定版权文本、链接及其编码源，不手工修改生成产物。
- R5：不改变订单状态机、支付/退款业务规则，也不扩大超级管理员既有旁路规则。

## Child Task Map

- `07-16-service-order-permissions`：R1–R3、R5；负责数据库迁移、后端权限防线、商家后台按钮权限和回归验证。
- `07-16-remove-merchant-copyright`：R4；负责商家后台源代码清理和构建验证。

## Cross-child Acceptance Criteria

- [ ] 新增管理员 `guanxing` 通过其既有角色授权可调用开始服务、完成服务、服务前退款；未授权普通管理员仍被后端拒绝。
- [ ] 角色管理树不再显示发货、确认收货、订单导出等旧实物操作，显示三个可独立勾选的服务动作。
- [ ] 登录后任意商家后台页面不再渲染指定版权文字或跳转链接。
- [ ] 商家后台源代码与新构建产物中均不存在该版权文字、链接或原编码常量。
- [ ] 两个子任务均通过各自质量门后再做整体回归。

## Out of Scope

- 删除实物订单、物流、导出相关后端业务代码或数据库业务表。
- 修改小程序、平台总后台或登录页中与本声明无关的第三方许可证。
- 直接部署生产、修改生产角色或生产数据库；本任务只交付可审计迁移和发布方案，生产执行走既有部署流程。
