测试设备: Android 真机 (RMX3781, v8.0.71)

\=== 问题描述 ===

调用 wx.requestVirtualPayment 始终返回 errCode: -15005 SIGNATURE\_INVALID。

已测试沙箱(env=1)和正式(env=0)两个环境，均失败。

三个道具 (member\_trial\_7d, member\_monthly, member\_yearly) 在后台均已发布。

\=== 已排查项 ===

1\. AppKey 已验证：现网 VP\_APPKEY 与后台一致

2\. paySig：URL编码排序 + &key=AppKey + HMAC-SHA256 → hex，多次手动验算 MATCH

3\. signature：offerId/openid/outTradeNo/zoneId/env 排序 + HMAC-SHA256(session\_key)

4\. session\_key：支付前通过 wx.login() 重新获取 code → code2session 刷新

5\. signData 格式：JSON，按ASCII排序，不含 paySig/signature 独立字段

6\. 道具已发布：后台"线上版本"确认三个道具均为"已发布"
